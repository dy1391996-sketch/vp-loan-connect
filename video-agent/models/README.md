Local neural model cache
========================

This directory holds LTX-Video weights downloaded by `scripts/install-neural.sh`.

Do not commit files from here. Approximate first-model size: 6.5 GB download,
12 GB disk. Only install on Apple Silicon or NVIDIA.

Selected model: Lightricks/LTX-Video (2B). Not Wan 14B / Hunyuan / LTX 13B.
