## Scope

Organic Instagram only. This folder does **not** configure Ads Manager, budgets, Boost Post, Pixel, or CAPI.

## Generate assets

```bash
node marketing/instagram/scripts/render-instagram-assets.mjs
node marketing/instagram/scripts/validate-instagram-content.mjs
```

## Structure

- `profile/` — 1080×1080 DP
- `posts/01`–`36/` — 1080×1350 PNG + caption + alt + meta
- `highlights/` — 7 covers
- `stories/` — 1080×1920 story frames
- `reels/` — 6 educational reel packages (text-led)
- `metadata/` — master CSV + 30-day calendar + publishing status
- `audit/` — compliance + connection + execution logs

## Public contact rules

Website Quick Apply + Instagram DM (general guidance only). No public phone / WhatsApp / Call CTA.
